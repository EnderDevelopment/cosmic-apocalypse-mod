# Cosmic Apocalypse Mod

Experience a cosmic horror apocalypse in Minecraft with custom events and entities.

## Features

- Cosmic apocalypse event with custom command
- Network synchronization for multiplayer support
- Cinematic HUD with warnings and visual effects
- Atmospheric world changes including red-tinted sky and increased fog density
- Custom corrupted mobs and a celestial boss entity
- Ambient sounds and boss roar sound effects

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or later
- Fabric API
- Geckolib

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

### Commands

- `/apocalypse start` - Begin the cosmic apocalypse event.

### Permissions

- Players need the appropriate permissions to use the `/apocalypse` command.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
